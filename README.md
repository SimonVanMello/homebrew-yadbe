# Homebrew tap for yadbe

[yadbe](https://github.com/SimonVanMello/yadbe) is a local, cross-platform database explorer.

```bash
brew install --cask simonvanmello/yadbe/yadbe
```

`Casks/yadbe.rb` is written by yadbe's release workflow each time a release is published: do not edit it by hand. The app updates itself, so `brew upgrade` leaves it alone.

yadbe is not code signed yet: on the first launch, allow it in System Settings → Privacy & Security → **Open Anyway**.
